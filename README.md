# 👗 LoreZone – Outfit Recommendation System

LoreZone is a smart **outfit recommendation system** that suggests clothing options based on a user’s **basic characteristics** such as **skin tone, height, occasion, and price preference**.  
It also includes features for discovering **ongoing offers**, **fashion events**, **job opportunities**, and **trending styles** — making it your one-stop fashion companion.

---

## 🚀 Features

### 🧥 Outfit Recommendation
- Suggests outfits based on:
  - Skin tone  
  - Height  
  - Occasion  
  - Price range  

### 💸 Offers & Deals
- Displays **current ongoing offers** from various fashion companies.

### 🎉 Events
- Shows **upcoming fashion events** with **dates** and **details**.

### 💼 Job Opportunities
- Lists **fashion-related job openings** and **career opportunities**.

### 🔥 Trending Styles
- Displays **trending clothes**, **fashion news**, and **style inspiration**.

### 📸 Watch Me
- Allows users to view **posted images** and discover **popular looks**.

---

## 🛠️ Tech Stack

**Frontend:** React.js, Bootstrap, CSS, JavaScript  
**Backend:** Node.js, Express.js  
**Database:** MySQL (or other as configured)  
**Deployment:** Render (Backend), Netlify/Vercel (Frontend)

---
### 1️⃣ Clone the Repository

git clone https://github.com/Arpenaboyina/LoreZone

### 2️⃣ Install Dependencies

Navigate into each folder and install the required modules:

Frontend
cd frontend
npm install

Backend
cd ../backend
npm install

### 3️⃣ Run the Project
Start Backend
cd backend
npm start

Start Frontend

Open another terminal and run:

cd frontend
npm start

### 4️⃣ API Configuration

In the frontend, update the API URLs to point to your backend.
Replace the localhost URL with your Render backend deployment link once deployed.
