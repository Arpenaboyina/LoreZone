# LoreZone - Outfit Recommendation System 👕
A full-stack outfit recommendation website built with React.js, Node.js, and Express.

## 🚀 Features
- Personalized outfit recommendations
- Integration with AI-based style suggestions
- Separate frontend (React) and backend (Express)
- User-friendly and mobile-responsive design

## 🛠️ Tech Stack
- **Frontend:** React.js, HTML, CSS, JavaScript
- **Backend:** Node.js, Express
- **Database:** MongoDB / MySQL
